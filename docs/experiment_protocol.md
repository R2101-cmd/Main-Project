# Experiment protocol

Prepare a reviewed, licensed dataset with stable vacancy IDs, source timestamps, evidence states, and manually reviewed lineage groups. Validate records, freeze the annotation and threshold configuration, then assign train/validation/test partitions by lineage group and employer when feasible. Train the TF-IDF/logistic-regression baseline only on training data. Run naive and lineage-aware methods on the same held-out cases. Save configuration, dataset version, predictions, metrics, and error analysis under `artifacts/experiments/`.

The pilot can be reproduced with `python -m src.evaluation.runner --data data/annotations/pilot.jsonl --output artifacts/experiments/pilot_results.json`. The runner rejects vacancy-group leakage, reports overall evidence coverage and consolidation, and evaluates the held-out test partition. With this small pilot the text baseline may be reported as not run when the training partition lacks two authorization classes; this is an honest data limitation, not a substitute for a result. Run `pytest -q` for deterministic behavioral checks. Do not generalize pilot metrics or claim improvement from this sample.

## Proposed collection template

Before collection begins, freeze the employer list, collection dates, source types, and sampling seed in a versioned protocol file. Select employers across sectors and sizes for a stated reason, then sample vacancies from official career pages and public recruitment platforms during the same period; do not sample only suspicious advertisements. Include accessible pages and record failed, blocked, expired, and redirected pages without treating failure as fraud. Search for reposts using vacancy identifiers, application destinations, contact details, and text similarity, then mark relationships as original, copied/derived, independent, or unknown only after review. Retain only necessary public information, hash or snapshot retrieved content where permitted, and avoid collecting applicant or private contact data. Ambiguous cases remain unresolved.
