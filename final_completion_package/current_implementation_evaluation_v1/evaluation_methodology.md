# Methodology

A is `src.ml.text_classifier.TextBaseline`: TF-IDF word unigrams/bigrams plus Logistic Regression, fitted only on the existing Stage 7A training partition (`train.jsonl`, `train_labels.jsonl`), using seed 20261116. It predicts from advertisement text alone. B calls production `src.aggregation.rules.naive()` on each input evidence list. C raw calls production `src.aggregation.rules.lineage_aware()`; C live follows the app wrapper: relationship/status qualification, `qualifying_independent_source_count()`, then `assess()`. The same 150 inputs were sent to every approach. New expected labels and scenario data were only read for scoring after prediction vectors were written. No thresholds or rules were tuned. Benchmark seed: 20261115. Synthetic design labels are not human-reviewed ground truth.

Harness audit: existing `src.evaluation.synthetic_v2.predict_test_records()` calls raw `lineage_aware()` but does not apply the live `assess()` policy. This package reports C raw and C live separately, with the live output using the same field mapping as `app.py`. The shipped authority config has zero real-world mappings. Benchmark evidence carries synthetic authority attributes only to exercise policy flow; it does not establish actual employer or ATS ownership.
