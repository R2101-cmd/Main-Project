# Read-only real dataset descriptive analysis

This package integrates the Stripe (780) and Stage 4F (2,200) advertisement cohorts in memory and checks the proposed unified CSV by exact case-ID set equality. Naukri is analyzed separately. Source files are read only; evidence and lineage candidate tables are summarized separately.

Evidence-state values are preserved as source classifications. Historical `independent_official_confirmation` is not interpreted as independently adjudicated vacancy authorization. Lineage pairs remain candidates unless their source review fields explicitly indicate adjudication.

## Limits

The cohort labels are blank, pending or unreviewed; therefore this is descriptive analysis only. It does not provide real-world accuracy, precision, recall, F1, or false-assurance performance. Canonical vacancy IDs are source normalization identifiers, not confirmed lineage.
